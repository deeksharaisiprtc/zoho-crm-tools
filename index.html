Call Flows
📞

Inbound Call Flow

Inbound ▼
1
Call Offered

Phone rings. A call panel appears with caller info preview.

2
Answer the Call

Pick up. CRM searches for a matching customer record automatically.

3
Screen Pop

CRM record pops based on match result (see Screen Pop table below).

4
Add Notes (Optional)

Select Notes under call controls → type in 8x8 section or scroll to Zoho CRM notes.

5
Hang Up

Click Hang up. Post-processing time begins.

6
Disposition & Wrap Up

Select a disposition code if required, then click Wrap up.

7
Call Log Generated

Automatic log with transaction ID, times, duration, tenant ID, and more.

⚠ Note: If a call times out without being answered, the 8x8 app automatically changes your status to On Break.
📤

Outbound Call Flow

Outbound ▼
1
Option A – Contact Center App

Dial directly from the 8x8 Contact Center app.

2
Option B – Click-to-Dial

Click a phone number on any Contact, Lead, Account, or Vendor in Zoho CRM (if click-to-dial is configured).

3
Select Dialing Reason

If phone codes are set up by your admin, select the dialing reason when prompted before the call connects.

🖥

Screen Pop Behavior

Reference ▼
Match Result
What Happens
🔴 No Match
No screen pop during call. After call ends, a log opens in a new tab — create a new Contact or Lead and assign the log.
🟢 Single Match
Customer record pops immediately for preview. After call, log is auto-linked to that record.
🟡 Multiple Matches
No auto pop. Match count shows on call panel. Click the avatar icon to manually select the right record. Log links to selected record (default: first in list).
